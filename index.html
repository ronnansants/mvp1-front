Sobre o projeto

Este projeto foi desenvolvido como MVP da disciplina de Desenvolvimento Full Stack Básico da pós-graduação da PUC-Rio. Seu objetivo é oferecer uma aplicação web simples e funcional, aplicando conceitos de front-end, back-end e integração com banco de dados.

As tecnologias utilizadas foram HTML, CSS e JavaScript puro no front-end, e com Python, Flask, Swagger e SQLite no back-end, seguindo a proposta acadêmica de separação entre cliente e servidor e uso de API documentada.

Finalidade

A finalidade deste sistema é facilitar o gerenciamento de contatos pessoais ou profissionais em uma interface prática, organizada e acessível. O usuário pode cadastrar informações importantes como nome, sobrenome, apelido, celular e e-mail.

Além de resolver um problema real de organização, o projeto também demonstra na prática a construção de uma SPA conectada a uma API REST com operações completas de cadastro, listagem, atualização e remoção de dados.

Sobre mim

Busquei desenvolver uma aplicação clara e funcional, demonstrando evolução no uso de tecnologias de front-end e back-end, além da integração com banco de dados e documentação de API.
